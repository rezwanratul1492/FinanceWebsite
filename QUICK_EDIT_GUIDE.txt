FOR A SIMPLE TEXT CHANGE:
1. Open the GitHub repository.
2. Open index.html.
3. Click Edit (pencil icon).
4. Press Ctrl+F and search for the exact existing text.
5. Change only the text you need.
6. Commit changes.

DO NOT PLACE PASSWORDS OR SUPABASE SECRET/SERVICE_ROLE KEYS IN index.html.
